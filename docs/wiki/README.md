# Player wiki source

These English Markdown files are the versioned source of the [GitHub player wiki](https://github.com/Vivoxti/AgriCraft-ReReloaded/wiki). `Home.md` is its landing page; `_Sidebar.md` and `_Footer.md` are GitHub Wiki navigation.

Use [Compatibility-Overview.md](Compatibility-Overview.md) to find a module and [About-These-Guides.md](About-These-Guides.md) for release scope and evidence. Crop catalogs document the data in both 4.0.20 release archives. The module articles explain practical setup, progression, exact defaults and support limits.

When updating the wiki, edit these sources and publish the same pages to the repository's separate wiki Git repository. Publish only the wiki pages and navigation, not this source README. Keep all prose in English and verify linked page names, source references and balance tables before publishing.
