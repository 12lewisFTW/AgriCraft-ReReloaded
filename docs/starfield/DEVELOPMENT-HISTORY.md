# Starfield integration development history

Historical development notes before release 4.0.20. Current support and verification are documented in the user guide and acceptance report.

## Unreleased — Starfield compatibility development

- Missing or unverified Starfield no longer installs gameplay/chunk/tick listeners, native item-use mixins, client rendering/cache hooks, magnifying-glass inspector or Jade crop providers. Dependency availability is cached from loader metadata at startup; network channel declarations remain stable without sending native crop packets.
- Canceled iteration 14: strength does not increase the native giant chance.
- Giant formation now emits returned sticks above the complete native shape. Real-client checks reproduced items being pushed underneath farmland by the giant; all three materials now remain collectible after cutting it.
- Native seeds now plant into empty single sticks through their original placement gates. Players can attach one stick material to an existing native root/upper part and remove it with sneak + empty hand. One-shot harvest retains empty sticks; destructive/natural removal returns material once, with rollback/transfer/creative guards.
- Render the existing wooden, iron and obsidian models around loaded native roots through a local chunk index. Explicit unwatch messages clear sidecars after long teleports, where the vanilla client unload event can be skipped.
- Direct planting of harvested coffee beans preserves their full produce genotype.
- Added the English and Russian Jade inspection setting translations required when returning to the menu after disconnecting.
- Real IF gatherer and PNC drone harvest operations verify inherited output and single consumption. PNC item filters now use native produce metadata instead of the crop's empty block-breaking loot table.
- Added a 4096-block native farm benchmark, opt-in two-client acceptance harness, official older-version loading profile and isolated installed-release restart check. Results and remaining release limits: `docs/starfield/ACCEPTANCE-RU.md`.

- Corrected legacy chunk migration to retain the local Y offset within each section; previously plants away from a section boundary could be missed. Native phase/day state is preserved.
- Release regression: chunk-indexed genome snapshots and one migration scan per loaded chunk, with no repeated block traversal for each watcher. Save schema remains 1; malformed/future data remains preserved.
- Disabled native wild-seed transformation now preserves existing dormant UUID/genome/sticks across reactivation, while native growth/selection continues unchanged.
- Added cross-process enabled → disabled → enabled world migration, 16,384-entry SavedData checks and ordinary multiplayer inspection checks. Added a consolidated Russian user guide and pinned dependency/material review. Completion acceptance verifies stick placement/rendering, two real clients and installed-release persistence; no version bump or publication.

- Optional NeoForge integration for the verified Starfield Pastoral `0.6.3fix1`: native crop catalog, preserved seed genomes, planting identity and trowel transfer. Native seed placement into empty single sticks and all three attached stick models are implemented.
- Paired native daily-growth checks cover baseline maturity, dry days, soils, seasons, fertilizer, real chunk unload, offline farm catch-up and full server restart. Native Starfield remains the only calendar/phase executor.
- Native hand/scythe harvesting retains Starfield quality, quantity, farming XP, permissions and regrow days. Canceled or throwing item creation rolls back the crop and partial drops; repeated clicks and nested harvests cannot duplicate output. AgriCraft tool actions no longer fall through to ordinary hand harvesting. Destructive block breaking still uses its separate native path.
- Seed Analyzer accepts all 50 supported native Starfield seed types without replacing their items or losing genomes/components. Magnifying glass, Jade and The One Probe share native phase, conditional remaining-day, water, season and gene information. Server checks protect analyzer menus and trowel actions; rakes, clippers and seed bags safely refuse unsupported native actions. Native-to-AgriSeed conversion remains unsupported; see the acceptance report for graphical client verification.
- AgriCraft sprinklers water native Starfield farmland and garden pots through their existing water budget, range and obstacle checks; sandy/infertile soil restrictions remain native. Native crops receive no extra random growth ticks, and overlapping irrigation cannot add calendar/regrow days. Continuously active sprinklers now mark consumed water and partial sweep progress for saving; sweeps no longer load neighbouring chunks. Giant forms remain outside this irrigation milestone.
- Empty double sticks breed native Starfield offspring from mature neighbouring roots with or without attached sticks. The active AgriCraft selection/clone/combine rules inherit both alleles and apply configured fertility/mutativity; native mutation recipes participate in species dominance. Different species require an explicit recipe, with no new production recipes. Offspring get fresh native progress/UUID and retain stick material; canceled/throwing placement restores empty doubles. Native soil/season/space gates remain in force, upper carriers do not count as parents, and parent readiness reads do not repair or advance native phases.
- Growth genes shorten freshly calculated native phases after fertilizer/profession effects and initialize shorter regrow countdowns, retaining native water/calendar rules and positive-day limits. Gain genes multiply primary hand/scythe harvest stacks once before transactional publication, preserving quality/components, native side products, stack limits and XP. Configured minima preserve native behavior; maxima halve positive durations with upward rounding and double primary counts. Junimo output now receives the same primary gain/genome handling through its native automation context; destructive breaking and giant harvest output retain their separate native paths.
- Strength genes recover a bounded fraction of native infertile-soil skips, with maximum strength removing this penalty; native soil progress still settles once and water/suitability gates remain. Soil samples depend only on the historical day, consume no world randomness and cannot be rerolled by reload or stick changes. Resistance grants up to three calendar days after the last allowed season, pausing growth/regrow and excluding paused roots from giant formation while allowing mature harvest. Seasonal immunity and native farm grace retain their original behavior. Inspection reports the inclusive remaining grace; actual two-process restart checks preserve soil remainder and the season anchor.
- All 37 multipart species retain native block states/models, synchronize their upper carriers, harvest once and clean both halves/genomes/native registration after support loss or partial destruction. Rice/taro retain source-water auto-watering and speed; fiber retains dry growth, seasonal appearance, scythe requirement and normal quality. Trowel and breeding placement now enforce the native cactus location gate.
- Wild seed maturity retains the source genotype, UUID, seed components and stick material on the native selected forage form without registering another daily crop. Inspection identifies the actual forage; trowel transfer and breeding preserve its source wild-seed species. Planted forage pickup applies gain to native products once, preserves foraging quality/professions/XP and rolls back rejected output. Native seasonal removal cleans the sidecar; world-generated forage is not assigned genes. Destructive breaking retains its separate native output path.
- All five native giant crops can form with attached sticks using Starfield's original 3×3 footprint, mature/watered trigger, 1% daily chance and native space/farm rules. Successful replacement returns each attached stick material once; canceled, throwing or reentrant restitution restores both crop parts, genomes, UUIDs and native progress without same-day rerolls. Giant harvest retains native tools, quantity, quality and XP; it receives no arbitrary parent genome or gain multiplier. Corrupt/future sidecar data blocks replacement before attachments are consumed.

- Primary native crop produce now carries both genome alleles through the real seed maker into corresponding seeds, including planted seasonal forage. Native counts, exceptional ancient/mixed/foreign output, simulation, partial extraction and machine persistence stay native. Invalid heredity rejects before input consumption; artisan outputs do not acquire crop genes.
- AgriCraft automation and the real Create harvester use the native Junimo context without fake players/tools or farming XP. Native quality/randomness/side products survive, primary gain applies once and multipart/regrow transitions cannot be harvested twice. Unsupported forage/giant paths refuse Create destructive fallback. A throwing external inventory sink leaves the crop committed to prevent retry duplication; arbitrary inventory rollback is outside the consumer API.
