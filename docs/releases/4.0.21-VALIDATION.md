# Release 4.0.21 verification

Verified on October 14, 2026, using Java 21.0.10 and Minecraft 1.21.1.

| Check | Result | Local evidence (ignored build output) |
| --- | --- | --- |
| NeoForge and Fabric production builds | Both succeeded | `build/release-4.0.21-build.log` |
| Release version, unique ZIP entries, all JSON, sprinkler models/texture | Both main archives passed; 3,962 JSON entries per archive | `build/release-4.0.21-audit.json` |
| Development-source/resource isolation | All six main, sources and dev-shadow archives passed | `tests/starfield/verify_release.py` |
| Actual NeoForge client model baking | Body: 11 quads; rotating blades: 22; inventory item: 33. Every quad uses `agricraft:block/sprinkler` | `build/release-4.0.21-validation/client-4.0.21/launch.log` |
| Actual installed NeoForge client/server crop interactions | 39/39 scripted interactions passed | `build/release-4.0.21-validation/server-4.0.21/issue2-network-results.txt` |

The gameplay check installs the final 4.0.21 production JAR on both the client and an ordinary dedicated server with NeoForge 21.1.226. Expanded Delight 0.1.4, Farmer's Delight 1.3.4 and KubeJS 2101.7.2-build.377 load the unchanged chili-pepper definition attached to [issue #2](https://github.com/Vivoxti/AgriCraft-ReReloaded/issues/2). Plants are placed through native seed use on crop sticks and prepared at a mature or immature stage; natural growth is not part of this check. Clicks execute through Minecraft's real client interaction handler and network, with both client and server sneaking state observed.

Thirteen scenarios run three times each: main-hand and offhand clipping, with and without sneaking; an ordinary stick in the main hand while the offhand holds clippers; clippers in both hands; ordinary empty-handed harvesting; immature crops with clippers in either hand; empty single/double sticks with offhand clippers; and ordinary removal of the additional pair of cross sticks with empty hands. Offhand clipping now yields the configured 3–8 peppers and resets growth to stage 0. Ordinary harvesting remains at 1–2 peppers and stage 1. Immature plants and empty sticks are not changed by clippers, and ordinary removal returns one sticks item.

The model/texture from [issue #3](https://github.com/Vivoxti/AgriCraft-ReReloaded/issues/3) is credited to 12lewisFTW. Archive validation compares all three model files and the 32×32 PNG with their source bytes, checks geometry and UV ranges, and verifies the actual client resolves the additional blade model. Existing rotation interpolation is retained. This is a resource-loading and gameplay validation, not a claim of manual visual inspection or new Fabric gameplay testing. Fabric builds and archive checks passed; the scripted gameplay/model checks ran on NeoForge. Unrelated integration suites from 4.0.20 were not rerun for this patch.

The development probe is a separate local test mod and is not included in either release. The dedicated server saved its world and exited normally; the client also stopped.
