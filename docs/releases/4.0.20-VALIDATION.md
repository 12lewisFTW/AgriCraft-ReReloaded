The official Starfield 0.6.3fix1 JAR and 251 reference source blobs were verified offline against the dependency lock; the catalog contains 50 crops. Starfield remains an optional compile-only dependency and is not distributed inside AgriCraft.

Datagen finished all providers and wrote its cache for 3832 generated entries. Its development JVM then remained alive after the main thread ended, with waiting worker pools and `DestroyJavaVM` in the thread dump. The completed process was stopped explicitly; this run is not reported as a successful Gradle exit. Generated resources were subsequently compiled and validated in both release JARs. Evidence: `build/release-4.0.20-datagen.log` and `build/release-4.0.20-datagen-threads.txt`. Both ordinary installed-server JVMs exited normally without a development launcher or test shutdown code.

The earlier graphical and ordinary-gameplay checks are recorded in [completion acceptance](../starfield/ACCEPTANCE-RU.md) and [gameplay acceptance](../starfield/GAMEPLAY-ACCEPTANCE-RU.md). They are historical evidence; graphical client tests were not rerun during this release preparation. Unsupported native actions and the unresolved historical shutdown incident remain documented in those reports; no unknown root-cause fix is claimed.
